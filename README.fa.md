# نمیر کافه — وب‌سایت منو با پنل مدیریت و پایگاه‌داده‌ی آنلاین

## بک‌اند انتخاب‌شده: Supabase

| نیاز | راه‌حل |
|---|---|
| پایگاه‌داده‌ی دائمی | PostgreSQL (جدول‌های `products`، `categories`، `site_settings`، `login_history`) |
| همگام‌سازی لحظه‌ای | Supabase Realtime (+ سیگنال `sync` و بازخوانی خودکار هنگام بازگشت به تب یا قطع و وصل اینترنت) |
| ذخیره‌ی تصاویر | Supabase Storage، باکت عمومی `namir-assets` (لوگو، عکس محصول، عکس دسته) |
| امنیت دسترسی | Row Level Security: بازدیدکننده فقط می‌خواند، فقط حساب مدیر می‌نویسد |
| ورود مدیر | تابع Edge به نام `admin-login` که نام کاربری و گذرواژه را **سمت سرور** با Secret ها مقایسه می‌کند |

چرا Supabase؟ هر پنج نیازِ دیتابیس، احراز هویت، ذخیره‌ی فایل، Realtime و سیاست‌های دسترسی را یکجا دارد. سایت هم فقط فایل استاتیک است و روی هر هاست رایگانی اجرا می‌شود. فایل HTML تولید نمی‌شود و `localStorage` پایگاه‌داده نیست. فقط انتخاب تم روشن یا تاریک و پرچم «انیمیشن آغازین امروز دیده شد» در مرورگر بازدیدکننده می‌ماند.

## راه‌اندازی (حدود ۱۵ دقیقه)

### ۱) ساخت پروژه
1. در [supabase.com](https://supabase.com) وارد شوید و **New project** بسازید (ناحیه‌ی نزدیک، مثلاً Frankfurt).
2. بعد از ساخته شدن، از **Project Settings → API** این دو مقدار را بردارید: `Project URL` و `anon public key`.

### ۲) ساخت جدول‌ها، سیاست‌های امنیتی، باکت تصاویر و داده‌ی اولیه
در **SQL Editor → New query** محتوای فایل `supabase/schema.sql` را کامل Paste و **Run** کنید. این فایل موارد زیر را می‌سازد:
- جدول‌ها، دسته‌ها و محصولات نمونه
- تنظیمات پیش‌فرض: نام کافه، رنگ‌ها، ساعت کاری شنبه تا جمعه ۰۵:۳۰ تا ۲۳:۰۰، شماره و اینستاگرام
- سیاست‌های RLS
- باکت `namir-assets`
- فعال‌سازی Realtime

### ۳) ⚠️ بستن ثبت‌نام (بسیار مهم)
**Authentication → Sign In / Providers → Email** را باز کنید و گزینه‌ی **Allow new users to sign up** را **خاموش** کنید. گزینه‌ی **Allow anonymous sign-ins** هم باید خاموش بماند، که به‌صورت پیش‌فرض خاموش است.
سیاست‌های نوشتن برای نقش `authenticated` است و تنها کاربر مدیر (که خود تابع Edge می‌سازد) باید چنین نقشی داشته باشد. اگر ثبت‌نام باز بماند، هر کسی می‌تواند حساب بسازد و منو را تغییر دهد.

### ۴) استقرار تابع ورود مدیر
با [Supabase CLI](https://supabase.com/docs/guides/cli):
```bash
npm i -g supabase
supabase login
supabase link --project-ref <PROJECT_REF>        # شناسه‌ی پروژه، در آدرس داشبورد
supabase secrets set ADMIN_USERNAME="Manager" ADMIN_PASSWORD="webmanagecafe"
supabase functions deploy admin-login
```
- نام کاربری و گذرواژه فقط در Secret های سرور هستند و در هیچ فایل فرانت‌اند نیامده‌اند.
- پیشنهاد جدی: گذرواژه‌ی `webmanagecafe` در گفتگو نوشته شده است. بعد از راه‌اندازی با همان دستور `secrets set` آن را عوض کنید. تابع در اولین ورود با گذرواژه‌ی جدید خودش را همگام می‌کند.
- مدیر دیگری ساخته نمی‌شود. نه صفحه‌ی ثبت‌نام وجود دارد و نه گزینه‌ی افزودن مدیر.
- محافظ حمله‌ی حدسی: بعد از ۸ ورود ناموفق از یک IP در ۱۰ دقیقه، ورود موقتاً بسته می‌شود.

### ۵) اتصال سایت
فایل `public/js/config.js` را باز کنید و دو مقدار را جایگذاری کنید:
```js
export const SUPABASE_URL = "https://xxxxxxxx.supabase.co";
export const SUPABASE_ANON_KEY = "eyJ...";   // فقط anon key؛ هرگز service_role
```
کلید `anon` عمومی است و ایمنی را RLS تأمین می‌کند.

### ۶) انتشار سایت
پوشه‌ی **`public/`** را روی یکی از این‌ها آپلود کنید: Netlify (Drag & Drop)، Cloudflare Pages، Vercel یا GitHub Pages. پوشه‌های `supabase/` و `tests/` برای انتشار نیستند.

### ۷) اولین ورود
روی سایت، روی **نام کافه** در وسط نوار بالا کلیک کنید و با اطلاعات مدیر وارد شوید. آدرس یا دکمه‌ی دیگری برای ورود وجود ندارد.

## پنل مدیریت

| بخش | امکانات |
|---|---|
| ظاهر و هویت برند | نام (فارسی و لاتین)، شعار، لوگو، فونت متن و عنوان، اندازه‌ی متن، ۹ رنگ با پیش‌نمایش و بازگشت به پالت اصلی |
| محصولات | افزودن، ویرایش، حذف، آپلود یا حذف عکس، توضیحات، ترکیبات، قیمت، تخفیف (قیمت اصلی، قیمت تخفیف، دلیل، روشن یا خاموش)، دسته، ترتیب (▲▼)، نمایش یا مخفی، فیلتر و جستجو |
| دسته‌بندی‌ها | ساخت، تغییر نام، عکس یا آیکن، حذف، ترتیب، نمایش یا مخفی |
| اطلاعات کافه | عنوان، معرفی، توضیحات، اطلاعات عمومی |
| تماس، نشانی و ساعت کاری | موبایل، تلفن ثابت، نشانی، اینستاگرام (شناسه و لینک)، ایمیل، ساعت کاری هر روز (با گزینه‌ی تعطیل) |
| تنظیمات انیمیشن | روشن یا خاموش، لوگوی انیمیشن، حالت و مدت، رنگ پس‌زمینه، فقط یک‌بار در هر نشست، انیمیشن کارت‌ها و پاپ‌آپ، پیش‌نمایش |
| تاریخچه ورود | تاریخ شمسی، ساعت، موفق یا ناموفق، نام کاربری وارد‌شده، مرورگر، نوع دستگاه، سیستم‌عامل، IP، اندازه‌ی صفحه، زبان، منطقه‌ی زمانی |

هر ذخیره مستقیم در دیتابیس نوشته می‌شود و همه‌ی بازدیدکننده‌های باز، بدون رفرش، تغییر را می‌بینند.

## ساختار پروژه
```
public/                 ← این پوشه را منتشر کنید
  index.html
  css/style.css  css/admin.css
  js/config.js          ← کلیدهای عمومی Supabase
  js/app.js             ← سایت عمومی
  js/admin.js           ← پنل (فقط پس از کلیک روی نام کافه بارگذاری می‌شود)
  js/store.js           ← دریافت داده + Realtime
supabase/
  schema.sql
  functions/admin-login/index.ts
tests/                  ← تست‌های مرورگری (فقط برای توسعه)
```

## وضعیت تست — صادقانه
تست‌ها با Chrome واقعی و Playwright اجرا شدند (`node tests/run.mjs`، **۹۴ از ۹۴ بررسی موفق**، با اسکرین‌شات در `tests/shots/`). اما این محیط به اینترنت و سرویس Supabase دسترسی ندارد، پس تست‌ها روی یک **شبیه‌ساز درون‌حافظه‌ای** اجرا شدند که RLS، تابع Edge، Storage و Realtime را تقلید می‌کند.

**روی شبیه‌ساز تست شده است:** انیمیشن آغازین، لوگو و نوار بالا (چیدمان چپ، وسط و راست)، لینک‌های tel و اینستاگرام، اسکرول «درباره ما»، دسته‌ها، جستجو، پاپ‌آپ و بلور پس‌زمینه، تخفیف، تم تاریک و روشن و ماندگاری آن، ورود موفق و ناموفق، رد شدن نام کاربری یا گذرواژه‌ی اشتباه، مدیریت محصول و دسته و برند و اطلاعات و تماس و ساعت و انیمیشن، تاریخچه‌ی ورود، همگام‌سازی لحظه‌ای بین دو صفحه، آپلود عکس، دکمه‌ی بازگشت به بالا، ریسپانسیو موبایل (۳۹۰)، تبلت (۸۲۰) و دسکتاپ (۱۲۸۰) و نبود اسکرول افقی.

**هنوز روی Supabase واقعی تست نشده** و باید بعد از راه‌اندازی خودتان یک‌بار بررسی کنید:
1. ورود با Manager، و رد شدن گذرواژه‌ی اشتباه (و ثبت هر دو در تاریخچه)
2. افزودن محصول با عکس و دیدن آن در یک تب دیگرِ بدون ورود
3. مخفی کردن محصول و ناپدید شدن آن در تب بازدیدکننده
4. اگر Realtime روی پروژه فعال نباشد، سایت هر ۲۰ ثانیه خودش را تازه می‌کند و با بازگشت به تب هم بازخوانی می‌شود

**موارد باز:**
- هیچ عکس مرجع، لوگو یا ویدیو پیوست نشده بود. هویت بصری از پالت و توضیحات شما ساخته شد: لوگوی خطی فنجان پیش‌فرض و تصویر جایگزین برای محصولات بدون عکس. لوگوی اصلی و عکس‌ها را از پنل آپلود کنید و انیمیشن آغازین با آن لوگو اجرا می‌شود.
- فونت‌ها از Google Fonts بارگذاری می‌شوند (پیش‌فرض Vazirmatn).
- ویدیوی انیمیشن لوگو را ندیدم. انیمیشن آغازین چهار حالت دارد (بزرگ‌نمایی، از پایین، محو به واضح، ترسیم خطی) و مدتش قابل تنظیم است.
- شماره‌ی تلفن ثابت، نشانی و متن «درباره‌ی ما» نمونه‌اند و باید از پنل ویرایش شوند.
